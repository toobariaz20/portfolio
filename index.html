Backend · Architecture

Core Platform API

A schema-as-code backend. JSON DSL model definitions are validated against a JSON Schema and materialised into Sequelize models, PostgreSQL tables and generic, role-protected CRUD endpoints. A non-destructive sync only widens the schema, so the data model can change without data loss.

  • Event-driven workflow engine with a durable transactional outbox, replayer, dispatcher and time-based scheduler on Redis + BullMQ, with loop protection for self-triggering events.
  • Auth with JWT/JOSE and opaque refresh sessions, bcrypt hashing in request pipelines, and per-model role ACLs.
  • Stripe billing, Apple subscription reconciliation, Firebase push, Pusher realtime, transactional email, and S3 presigned uploads.
  • Jest + Supertest suites, Postman collections kept in sync with the API docs, and Docker builds deployed by GitHub Actions to AWS EC2.
